## Decisions made during the run

1. **Watched values read with two catalogs.** `frosty-mutator-values.py` stopped on the new
   rebuilt-cache catalog, which gives file GUID `d2cb993f…` to two test mutators (`MUT_CHIITest`,
   `MUT_PVE`). It was re-run through a wrapper that lists the baseline loaded-cache catalog first
   (the same fix the guide prescribes for the generators). Values unchanged. Not changed in the
   repo script; reported as a runner gap.
2. **New build, not held.** Layouts differ and assets were added and removed: the guide's
   new-build rule applies directly, so the run continued without the operator (2.1.2.0 was
   accepted by the operator; this one fits the written rule).
3. **Route list extended only by note-matching EBX routes.** Of 49 changed catalog routes outside
   the list, 9 EBX routes tied to note lines were added (3 UI widgets, the flag pole, 3 `MP_Dough`
   level layers, 2 moved `DiceAI` aiming constraints); character textures, meshes, physics and
   sound stay out, as in 2.1.2.0.
4. **Graph-body IDs copied from 2.1.2.0.** No expression-graph source changed by raw SHA-256, so
   no resource ID can have changed; the 300 bodies were still captured (300 of 300).
5. **Brief A done in the main session.** The notes have six lines; one states a stored value.
6. **Raw index order.** Multiplayer-copy folders are read last on both sides; otherwise a campaign
   copy in a 2.1.2.0 research folder won and two reflex lens meshes showed as false changes.
7. **Supply Pouch traced in full** at the operator's request (not a site item; heavily used
   gadget): worker `SP-supply-pouch`.
