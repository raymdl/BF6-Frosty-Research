## Decisions for this update

Agreed with the operator on 12 October 2026.

1. **Use the extended route list** for the post-update capture, so both sides match route
   for route. It becomes the new build's `raw-routes.txt` from the start. Do not edit
   `raw-routes.txt` in 1.4.3.5.
2. **Compare catalogs against the rebuilt-cache catalog** (`collection-fresh-cache`), never
   the loaded-cache one in `collection`. Frosty lists 1,014 more assets in a run that
   rebuilds its cache; against the wrong catalog they show as falsely new.
3. **Expect a new build, not a hotfix** (new season, maps, weapons, balance). If Stage 1
   confirms it: seal 1.4.3.5 and create the new build folder. The skill's decision step
   still decides; this is the expectation, not the result.
4. **Ignore REDSEC** items in the notes.
5. **Never decode or open a `materialgrid_win32` file directly.** Use
   `scripts/frosty-material-grid-inventory.py`.

Known baseline failures, expected again or explained:

- Two loot-card image routes (`T_UI_LootcardBG_BattlePickups_Minigun`, `_Railgun`): not in the catalog.
- `Common/Sound/System/LRM/BF03_System_LRM_CurveCollection`: fails from a loaded cache,
  succeeds after a rebuild. The post-update run rebuilds, so it may succeed there; that is
  not a change.
