# Per-map facts, Battlefield 6 build 2.1.1.0

Source: modes-out/<Mode>-maps.json (all modes) plus bt-maps.json (Breakthrough, 17 maps; modes-out/Breakthrough-maps.json holds only Wake Island and Railway to Golmud and is a newer partial copy; bt-maps.json used). Generated by modes-work/maps_gen.py. Coordinates are metres, x/z map plane.

Definitions: **layer** = the mode json for that map has at least one decoded gameplay instance. **shell** = assets/polygons/boxes only, no instances (schematic, telemetry or global-only stubs). Mode abbreviations: CQ=Conquest, BT=Breakthrough, RS=Rush, ESC=Escalation, PL=Payload, SAB=Sabotage, KOTH=KingOfTheHill, DOM=Domination, SP=Strikepoint, TDM=TeamDeathMatch, SDM=SquadDeathMatch, OBL=Obliteration, GNT=Gauntlet, FR=Freeroam, FLAG=Flag, CS=CarrierStrike, SPKY=SpookyRush, SQOBL=SquadObliteration, OPS=Operations. Vehicle class names are the data names (GMPF_VehicleSpawner_<class>), spaced; the files hold no per-class in-game vehicle model names.

## 4. Open questions and caveats

1. **Input files changed during the task.** modes-out/*-maps.json were rewritten at 08:41:54 on 21 Oct (now 18 maps per mode file, full asset paths such as `Game/GlacierMP/Levels/MP_Battery/_Layers_Gameplay/Conquest0`). This report uses the rewritten files. In them Iberian Offensive HAS a Conquest layer (50 instances) and a Rush layer (28), and Eastwood HAS a Rush layer (52 instances) and a Conquest layer (79), contrary to the brief's premises (taken from the older files). Still true: Iberian Offensive has no Breakthrough key, Saints Quarter has no Breakthrough, Conquest, Rush, Escalation or Payload layer, and Eastwood has no Payload layer. If the extractor is run again, regenerate with `python -I modes-work/maps_gen.py` (reads the same inputs).
2. **Breakthrough source.** modes-out/Breakthrough-maps.json holds only Wake Island and Railway to Golmud; the 17-map set is bt-maps.json (19 Oct, older extraction). The two were not compared for the 2 shared maps beyond the layer being present. bt-maps.json writes the faction as "Pax Armata"; this report prints it as Pax Armata (user-facing name) - the string in the extractor output should be fixed or confirmed.
3. **Shell-only layers.** Several mode files hold a map with assets but no decoded instances (listed in the "Shell only" column). Examples: Payload on Railway to Golmud, Team Deathmatch on Railway to Golmud, King of the Hill on Mirak Valley, Wake Island, Contaminated and Cairo Bazaar, Sabotage on Iberian Offensive, Wake Island and Tsuru Reef, Escalation on Area 51 and Vegas Strip. The files cannot say whether the layer genuinely does not exist or the extractor missed its gameplay asset (the shells are schematic/global/telemetry assets only).
4. **UI metadata covers only 11 maps.** UILevelDescriptionMetadata rows exist for the 11 maps with a "Default, Breakthrough, ..." tip list; the other 8 (Wake Island, Contaminated, Area 51, Railway to Golmud, Tsuru Reef, Vegas Strip, Cairo Bazaar, Hagental Base) have no row in ui-level-gamemode.json, so country, coordinates and advertised modes are unknown for them (in-game names from README-modes.md). Another asset may hold them.
5. **Tips lists are identical** for all 11 maps (BT, CQ, ESC, PL, RS, SDM, SP, TDM, DOM, KOTH). They are probably a generic template, not a statement of what each map supports (they list Payload for Eastwood, Firestorm, Mirak Valley, Empire State, Saints Quarter, which have no Payload layer, and Escalation/Breakthrough for Saints Quarter). They never list Sabotage (layers on 6 maps), Obliteration, Gauntlet or the others.
6. **Combat area.** For modes that contain a Combat/SpecialCombatArea instance, the listed polygons are those that contain that instance (the largest is usually an outer boundary, the smaller ones sub-areas). The instance position is only an anchor, so which polygon is the real play-area boundary is an inference. For modes without such an instance, "largest-poly" is the biggest polygon that holds at least 5 instances; that is a heuristic, not a stored combat area. Compare modes by the bbox figures, not by the labels.
7. **Team-to-faction.** factionOverrides are per mode layer; swapped team1/team2 between modes (12 of 19 maps) may reflect which side attacks or spawns on the left rather than a gameplay difference. The mapping "no override = team1 Alliance/NATO, team2 Coalition/Pax Armata" is from README-modes.md.
8. **Extent** is from instance positions only (including vehicle spawners at flight height; y reaches 1388 to 1800 on some maps, jets and delivery markers) and excludes exact (0,0,0) placeholders. Iberian Offensive (x 568..935) and Saints Quarter (x 239..406) use different coordinate frames/offsets although both are Gibraltar, Upper Town.
9. **Vehicle names.** The files give only spawner classes (GMPF_VehicleSpawner_<class>), not the in-game vehicle names; a spawner of class Tank or IFV does not say which model. Quad Bike, Dirt Bike and Golf Cart are PTV (personal transport) classes.
10. The "Flag" file holds only Strikepoint_Global shells; the other small files (CarrierStrike, SpookyRush, SquadObliteration, Operations, Freeroam, Gauntlet) are listed as modes with layer/shell where they hold instances or assets (CS = CarrierStrike, SPKY = SpookyRush, SQOBL = SquadObliteration, OPS = Operations), so the "Modes with a layer" counts for Tsuru Reef, Area 51, Cairo Bazaar and Mirak Valley include these special modes; the "core" table counts only the 11 mainstream modes.
