## [site-common]
SITE CONVENTIONS: COMMON (use whenever you compare with site data)
- The site intentionally models a bare-weapon baseline. Game default loadouts matter only when they explain a concrete stat discrepancy.
- Attachment values can be choice-level fields OR per-weapon under <choice>.frostyModifiers.<siteWeaponId>.<field> (or <field>ByWeapon / weaponOverrides maps); the per-weapon value takes precedence. Check all before calling anything unmodeled.
- GS modifier bindings may be keyed by the attachment's selector GUID OR by a separate condition token (e.g. U_WPM_ERG_BurstFireActive 588728fd-2ae7-4424-aa22-45d9b3c82ba0, as in L13/L59). Search both.
- Site weapon <-> source roots: use the run-root weapon-crosswalk.json named in your brief (site id, class, internal name, GS/WB/Ability raw paths and hashes).

## [recoil]
SITE CONVENTIONS: RECOIL
- Recoil tiers: amount = amount * amountMult^(amountExp + sum RecoilTierMods); variation = dirVar * dirVarMult^(dirVarExp + sum VariationTierMods). A site recoil tier mod equals the source ADDITIVE operand on RecoilAmountMultiplierExponent (Field_22ce7cf3) / RecoilDirectionVariationMultiplierExponent (Field_02433593), SAME sign; several bound operands may sum to one site value (L59).
