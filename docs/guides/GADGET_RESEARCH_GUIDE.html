Read this first

  1. A stored number is a setting, not a proven stat.The game files hold a huge number of values. We can read them exactly. We usually cannot say what unit they use or what they do in a match. A stored "40" next to the Repair Tool is not shown to be 40 health per second.
  2. Defaults can differ from what a gadget really uses.A registry default is a fallback value from a central table. An inherited default is a value a gadget picks up from a shared base type. A gadget's own value comes first. Example: the RPG-7V2 stores its own damage as 135, while its registry default says 125.
  3. The strongest evidence is a description that matches a stored value.When the game's own text says a number and the files hold the same number, the two agree and we trust the reading more. We have four clean cases: Hemostatic regeneration, the 2.2 second revive, MP-APS "up to 3", and MTN-55 timing. The next section shows them. Agreement still does not prove units or effects.
Game description
What the game itself says on a card or menu. Quoted as written.
Stored game value
A number found in the game files. We read it exactly. It is a setting, not a proven stat.
Inherited default
A value a weapon picks up from a shared base type, or a fallback from a central table. May not be what the weapon really uses.
EA patch notes
A number from an official EA update article, with its version. It may be out of date for the saved game build.
Our guess
Our own reading. Shown so you can see the reasoning. Not tested.

How sure means two things. First, did we read the number correctly from the game files. That is almost always yes, and we re-read many of them from the raw files. Second, do we know what the number does in a match. That is usually no.

Where text and numbers agree

These are the best results in the research. In each one the game says a number in words and the files store the same number. Read the last line of each box for what is still not proven.

Hemostatic smoke: regeneration

Game description
...provides 12.5hp/s health regen after 2.5s...
Stored game value
Regeneration rate 12.5 and regeneration delay 2.5, with a third slot of 0.

The units are still unproved, and the effect on a real soldier has not been observed.

Revive time with Hemostatic

Game description
...speeds up revival to 2.2s for all classes...
Stored game value
The squad revive stores a Support time of 2.2. The normal total time is 4.72.

The text says all classes, but the stored 2.2 sits in the Support entry.

MP-APS and EIDOS: interceptions

Game description
Can intercept up to three projectiles during a window of activation.
Stored game value
Max intercepts is stored as 3, with 1 and 10 in the other two slots. Both gadgets store the same three numbers.

Whether 3 is a limit per window, or something else, is a reading. The compiled logic is not read.

Proximity Grenade (MTN-55): timing

Game description
...scans for enemies once per second... marking their position... for a duration of two seconds.
Stored game value
Pulse 1 and duration 2.

Matching words and numbers is not a proof that those fields run the scan.

One near miss. The Restock Allies ability says reviving teammates takes only 1.7 seconds. We found no stored 1.7. The squad revive stores 4.72 and 2.2. Where 1.7 comes from is an open question.

Healing, supply and revive

Defibrillator L232

Game description

This equipment can revive both squad members and teammates. Charge paddles for a short duration to revive a downed soldier with full health. Can also inflict damage on enemies.

  • Stored game valueThe files hold a 13-row curve and two revive effects with six entries each. A separate damage effect also exists, which fits the "can also inflict damage" line.
  • EA patch notesEA update 1.2.3.0 says a 0.35 second minimum charge before a revive and a 1 second full charge. That is charge time, not the whole revive.
  • Stored game valueThe Supercharge perk links to a sprint-speed effect. No formula is read.

How sure Wiring: solid. Charge times: only from EA notes, not measured on the saved build.

Still unknown
  • How much health a revive gives and over what time.
  • How the curve is used.

Supply Pouch L233, L229

Game description

A single-use pouch to replenish ammo and medical supplies for the owner or their teammates. Fully restocks ammo capacity of the primary and secondary weapons and restores a portion of health.

  • EA patch notesEA update 1.0.1.0: deployed pouches cannot be picked up, vehicle healing was removed, a pouch gives one extra C4, and healing happens over time.
  • Stored game valueThe pouch and the crate share one healing layout. One true-or-false flag is true for the pouch and false for the crate. We do not know what it does.

How sure Wiring: solid. Amounts and timing: unknown.

Still unknown
  • How much health and ammo a pouch gives.
  • What the pouch-versus-crate flag does.
  • Whether the gas mask and night vision effects work.
